# Junyoung Yang — Portfolio

Personal portfolio focused on AI systems, multimodal retrieval, and agentic memory.

## Local preview

```bash
npm install
npm run dev
```

## GitHub Pages

The included workflow deploys automatically from `main`. In the repository settings,
set **Pages → Source** to **GitHub Actions**, then push the project to GitHub.

The workflow supports both a user site repository (`<username>.github.io`) and a
project site repository (`<username>.github.io/<repository>`).
